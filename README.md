`mend` is a Node.js 22 CLI that applies unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON edits to a tree of text files. It applies the entire patch or leaves the tree unchanged.

## Run it

```sh
node main.ts [options] [PATCH]
```

Run it with the target tree as the working directory. `PATCH` is the patch file. Omit it to read the patch from standard input.
